# Weekly course package format v1

Each week is one independent file: `courses/weekN-course.json` (no zero padding and no maximum week number). `catalog.json` is generated by `scripts/build.mjs` and must not be hand-maintained when using GitHub Actions.

Root fields: `schemaVersion: 1`, `week`, `title`, `summary`, `level`, `objectives`, `lessons`.

Each week contains exactly seven lessons. The `day` field uses a global sequence across weeks (Week 1 = 1–7, Week 2 = 8–14, and so on). Lesson IDs must be globally unique (`w01d01`, `w01d02`, ...). Each lesson has: `day`, `id`, `title`, `subtitle`, `minutes`, `grammar`, `vocabulary`, `listening`, `speaking`, `reading`, `writing`, `quiz`.

Vocabulary item: `word`, `ipa`, `zh`, `example`.
Listening: `title`, `transcript`, `questions[]`. Speaking: `prompt`, `sample`. Reading: `title`, `text`, `questions[]`. Writing: `prompt`, `checklist[]`. Quiz items: globally unique `id`, `type`, `prompt`, `options[]`, `answer`, `explanation`.

All lesson tasks must align with the chapter objective and taught grammar. Avoid using unintroduced grammar as a required answer. Every new week is validated by the build script before publication.
